# programming_vs_python

### What is programming?
Programming is giving step-by-step instructions to a computer to do a specific task.

### What is programming language?
A programming language is a set of rules and words that humans use to write instructions a computer can understand.

### What is python?
It is a simple, easy-to-read language used to tell a computer what to do.

### What is syntax?
It is just the grammar and spelling rules you have to follow when writing that code.

### Explain the difference between programming and python?
Programming is the actual skill of telling a computer what to do step by step, while Python is just one specific language you use to write those instructions.

### Explain What remained the same between pseudocode and python program?
The logic and the step-by-step thinking remain the exact same between pseudocode and Python.

### What changed?
Only syntax changed so that computer can actually read and run the code.
